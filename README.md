## 🔬 Current Project: Psychology & Economics of Poverty Literature Review

![CEGA Logo](streamlit/logo.png)

🔗 **Live Dashboard**: [psychology-literature-dashboard.streamlit.app](https://psychology-literature-dashboard.streamlit.app)

I'm leading the development of an innovative **interactive literature review dashboard** that transforms how researchers explore psychological consequences of poverty. This project bridges academic disciplines and enables evidence-based decision-making for effective interventions.

- **📊 Data Processing**: BigQuery integration, Google Sheets API, and OpenAlex API
- **🔍 NLP Features**: Sentence transformers, UMAP dimensionality reduction, and clustering
- **📈 Visualizations**: Dynamic charts (Sankey diagrams, heatmaps, interactive plots)
